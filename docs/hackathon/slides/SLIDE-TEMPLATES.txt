QUICK START GUIDE
═══════════════════════════════════════════════════════════════════

Google Slides:
1. Go to slides.google.com
2. Blank presentation
3. File → Page setup → Widescreen 16:9
4. Insert → Text box
5. Copy/paste content above
6. Format → Align → Center
7. Download → PNG

PowerPoint:
1. Open PowerPoint
2. Design → Slide Size → Widescreen 16:9
3. Insert → Text box
4. Copy/paste content above
5. Home → Align → Center
6. File → Export → PNG

Canva (easiest):
1. canva.com
2. "Presentation" template (1920x1080)
3. Replace text with content above
4. Download as PNG
