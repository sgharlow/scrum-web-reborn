# Quick Start: Create Your Slides in 20 Minutes

**Goal:** Create 5-7 simple slides for your demo video
**Time:** 20 minutes
**Tool:** Google Slides (free, easy, no install)

---

## Step 1: Open Google Slides (2 minutes)

1. Go to **https://slides.google.com**
2. Click **"Blank presentation"**
3. Click **File → Page setup → Widescreen (16:9)**
4. Delete the default title slide

---

## Step 2: Create Title Slide (3 minutes)

1. **Insert → New slide → Blank**
2. **Insert → Text box**
3. **Type:**
   ```
   Scrum Reborn

   99x More Reliable
   Real-Time Scrum Collaboration

   Built with AWS AppSync
   ```
4. **Format:**
   - Select all text
   - Font: Arial or Helvetica
   - Align: Center (Ctrl+Shift+E)
   - "Scrum Reborn": Size 72, Bold
   - "99x": Size 60, Bold, Green color
   - Rest: Size 36

5. **Background:**
   - Slide → Change background → #1F2937 (dark blue)
   - Text color → White

---

## Step 3: Problem Slide (3 minutes)

1. **Insert → New slide → Blank**
2. **Insert → Text box**
3. **Type:**
   ```
   The Problem: P2P WebRTC

   👤 ──X──> 🔥 ──X──> 👤
   User A   Firewall   User B

   ❌ NAT Traversal Issues
   ❌ Corporate Firewalls
   ❌ TURN Server Unreliable


   50% FAILURE RATE
   ```

4. **Format:**
   - Center align
   - Title: 48pt bold
   - Emojis: 40pt
   - Bullets: 32pt
   - "50% FAILURE RATE": 60pt bold RED (#EF4444)

5. **Background:** Light gray (#F3F4F6)

---

5. **Background:** White

---

## Step 5: Before/After Slide (4 minutes)

1. **Insert → New slide → Blank**
2. **Insert → Shape → Rectangle** (2 rectangles side by side)
3. **Left rectangle:**
   - Fill color: Light red (#FEE2E2)
   - Insert text box inside:
     ```
     BEFORE: P2P

     ❌ 50% Success
     ❌ NAT Issues
     ❌ Firewalls
     ❌ $50/month
     ```

4. **Right rectangle:**
   - Fill color: Light green (#D1FAE5)
   - Insert text box inside:
     ```
     AFTER: AppSync

     ✅ 99.5% Success
     ✅ Works Everywhere
     ✅ Port 443 Only
     ✅ $20/month
     ```

5. **Bottom:** Add text box:
   ```
   99x MORE RELIABLE
   ```
   - Size: 60pt bold
   - Background: Gold (#F59E0B)
   - Text: White

## Step 8: Download (1 minute)

1. **File → Download → PNG image (.png)**
2. Download **Current slide** for each slide
3. Save as: `01-title.png`, `02-problem.png`, etc.
4. Store in: `docs/hackathon/slides/`

## Tips for Success

### Do:
- ✅ Use large text (48pt+)
- ✅ High contrast colors
- ✅ Center align everything
- ✅ Minimal text per slide
- ✅ Use emojis for visual interest

### Don't:
- ❌ Small text (<24pt)
- ❌ Too much text (>7 lines)
- ❌ Low contrast (gray on gray)
- ❌ Fancy animations
- ❌ Cluttered layouts

## Using Your Slides in Video

### During Recording:

1. **Open slides in presentation mode** (press Present button)
2. **Share screen** in your recording software
3. **Show each slide** for 10-20 seconds while talking
4. **Transition smoothly** - press spacebar to advance
5. **Switch to live demo** for the demo portion (minutes 1:30-3:30)
6. **Return to slides** for metrics and call to action

### Slide Timing:
- Title slide: 10 seconds (while introducing yourself)
- Problem slide: 30 seconds (explaining P2P issues)
- Solution slide: 30 seconds (introducing AppSync)
- [Live demo: 2 minutes - no slides, screen recording]
- Before/After: 20 seconds (showing comparison)
- Metrics: 20 seconds (proving impact)
- Call to action: 10 seconds (ending)

**Total slide time: ~2 minutes out of 5-minute video**

## What If I Want Fancier Slides?

If you have more time (1-2 hours) and want professional slides:

1. **Use Canva:**
   - Go to canva.com
   - Search "Tech Pitch Deck"
   - Pick a template
   - Replace with your content
   - Download as PNG

2. **Use PowerPoint Templates:**
   - Search "modern presentation template"
   - Download free template
   - Replace content
   - Export as images

3. **Hire on Fiverr ($10-30):**
   - Search "presentation design"
   - Send your content from SLIDE-TEMPLATES.txt
   - Get slides in 24 hours

But honestly, simple slides work great! Judges care more about your demo and metrics than fancy graphics.
